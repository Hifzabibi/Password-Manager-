# 🔐 PassVault - Password Manager

PassVault is a simple and user-friendly full-stack password manager built with React.js, Node.js, Express.js, and MongoDB.

It allows users to securely manage their website credentials from a clean and modern interface.

---

## ✨ Features

- 🔐 Save website passwords
- 👁️ Show/Hide password
- 📋 Copy website URL
- 📋 Copy username
- 📋 Copy password
- ✏️ Edit saved passwords
- 🗑️ Delete passwords
- 📊 Display saved passwords in a table
- 💾 Store passwords in MongoDB
- 🔄 Fetch saved passwords from backend
- 🌐 React frontend with Express backend
- 🎨 Responsive and modern UI

---

## 🛠️ Technologies Used

### Frontend

- React.js
- JavaScript
- Tailwind CSS
- Lucide React
- Vite

### Backend

- Node.js
- Express.js
- MongoDB
- MongoDB Node.js Driver
- CORS
- dotenv
